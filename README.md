# YCLIENTS Audit Helper

Расширение для Google Chrome, которое помогает менеджерам сопровождения YCLIENTS проводить аудит клиентов без печати PDF-бланков. Чек-лист открывается прямо в браузере, а готовое резюме автоматически копируется в буфер обмена для вставки в примечание сделки в AmoCRM.

Помимо чек-листа и ссылок на все необходимые разделы филиала клиента, расширение содержит подсказки для кросс-продаж по интеграциям «Бьюти Бот» и «Чаевые», а также ускоряет передачу лидов партнёру.

На страницах yclients.com при наведении на ссылку настроек сети появляется кнопка, открывающая в фоне 4 раздела лояльности.

---

## Как это работает

1. Откройте страницу сделки в AmoCRM.
2. Нажмите на иконку расширения рядом с адресной строкой.
3. Расширение считывает данные сделки (ID YCLIENTS, статус, ответственного, город, часовой пояс и др.).
4. Открывается страница с чек-листом и вкладками-скриптами. Ссылки на разделы филиала уже содержат нужный ID.
5. Заполните чек-лист (или проведите разговор по нужному скрипту).
6. Нажмите **«Резюме»** — текст появится в поле и автоматически скопируется в буфер. Его можно отредактировать прямо на странице.
7. Вставьте текст в поле **«Примечание»** сделки в AmoCRM.

## Установка

1. Скачайте архив с расширением (https://github.com/sokolovsasha/yclients-audit-extension/archive/refs/heads/main.zip или зелёная кнопка **Download ZIP**) и распакуйте в любую папку.
2. Откройте Chrome и перейдите по адресу `chrome://extensions/`.
3. Включите справа сверху **«Режим разработчика»** (Developer mode).
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку, куда распаковали архив.
5. Иконка расширения появится в панели инструментов.

---

## Приватность

- Все данные обрабатываются локально в браузере.
- Никуда не отправляются, не сохраняются на серверах, не передаются третьим лицам.
- Результаты аудита и текст комментариев копируются только в буфер обмена по нажатию кнопки.

---

## Ограничения

- Расширение работает **только на страницах сделок AmoCRM** (`yclients.amocrm.ru/leads/detail/`).
- На других сайтах при нажатии на иконку расширение не откроет чек-лист и покажет индикатор `AMO`.
- Если ID YCLIENTS не найден в сделке, расширение покажет индикатор `ID`.
