У меня нет принтера, чтобы распечатывать бланки Чек-листов Аудита, поэтому я сделал расширение для Google Chrome. Оно помогает менеджерам сопровождения YCLIENTS проводить аудит клиентов и, возможно, спасает несколько деревьев.

# Как работает расширение

- Вы открываете страницу сделки в AmoCRM;
- Нажимаете на иконку расширения рядом с адресной строкой;
- Расширение считывает ID филиала на странице сделки;
- Открывается чек-лист аудита, в котором уже есть ссылки на все разделы филиала, где надо проверить активность клиента;
- Вы заполняете чек-лист, как если бы это был PDF-документ;
- Нажимаете кнопку **«Резюме»** — всё, что вы записали про филиал, автоматически копируется в буфер обмена.
- Вставляете этот текст в поле **«Примечание»** сделки в AmoCRM.

# Установка

1. Скачайте архив с расширением и распакуйте в любую папку.
2. Откройте Chrome, перейдите в `chrome://extensions/`.
3. Включите справа сверху **«Режим разработчика»** (Developer mode).
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку, куда распаковали архив.
5. Иконка расширения появится в панели инструментов.

# Важно

- Расширение работает **только на страницах сделок AmoCRM**.
- На других сайтах ничего не произойдёт.
- Данные никуда не передаются — всё работает на вашем компьютере в двух вкладках.
